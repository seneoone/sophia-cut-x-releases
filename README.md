# Sophia Cut-X — ตัวติดตั้ง

ที่เก็บนี้มีไว้ปล่อยตัวติดตั้งของ Sophia Cut-X (Windows) เท่านั้น ซอร์สโค้ดอยู่ในที่เก็บส่วนตัว

- ดาวน์โหลดเวอร์ชันล่าสุดที่ [Releases](../../releases/latest)
- ในโปรแกรม: ตั้งค่า → เวอร์ชันและการอัปเดต → ใส่ที่เก็บ `seneoone/sophia-cut-x-releases` เพื่อให้โปรแกรมตรวจหาเวอร์ชันใหม่ได้ (โปรแกรมแค่ตรวจและเปิดหน้าดาวน์โหลด ไม่ติดตั้งเอง)

ตัวติดตั้งมี FFmpeg (GPL v3) อยู่ด้วย — ดูรายละเอียดในหน้าของแต่ละเวอร์ชัน
